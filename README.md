# Spell Light Dynamic Shadows

Showcase media for **Spell Light Dynamic Shadows**, an Oblivion Remastered mod by [iammrmikeman](https://www.nexusmods.com/profile/iammrmikeman) / [iammrmikemanmods](https://github.com/iammrmikemanmods).

This repository hosts the animated GIFs embedded in the Nexus Mods description. Gameplay was recorded by the author in a dungeon test scene. The images show the mod in use; no generated game imagery is used.

The Nexus mod page is being prepared for author review and has not been published by this upload. This repository is not the mod installer.

Full-resolution source recordings remain separate from the optimized description GIFs. GIF is limited to indexed colour and has no audio.
